프로젝트에서 네 가지 설정을 수정했고, `npm test`에서 회귀 테스트 3개가 모두 통과했습니다. 수정 전에는 기존 테스트가 디버그 설정 검사에서 실패했습니다.

- [src/config.mjs](/private/tmp/trace-ai-multi/settings/src/config.mjs)에서 운영 디버그를 끄고, 개발 환경에서만 `DEBUG=true`로 켤 수 있게 했습니다. CORS 출처는 기존 테스트에 명시된 `https://app.example.test`로 제한했고, 서명 검증과 TLS 인증서 검증을 활성화했습니다.
- [test/security.test.mjs](/private/tmp/trace-ai-multi/settings/test/security.test.mjs)에서 별도 Node 프로세스로 운영 환경의 네 설정값, 환경 미지정 시 디버그 비활성화, 개발 환경에서의 명시적 활성화를 검증했습니다.

저장소에는 설정을 사용하는 서버, 서명 검증 코드, TLS 클라이언트가 없습니다. 따라서 운영 오류 응답의 디버그 세부 정보 노출 여부, 등록·미등록 출처별 CORS 응답 헤더, 서명 불일치 요청 및 신뢰되지 않은 인증서 연결의 거부 여부는 확인하지 못했습니다. 프로젝트에서 사용할 신뢰 키와 별도 CA도 확인할 수 없어 지정하지 못했습니다.
