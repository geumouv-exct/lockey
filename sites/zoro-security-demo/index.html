점검 방식
링크 점검 범위

설문 확인 시 입력한 공개 페이지를 한 번 읽습니다. 링크만 점검하면 인증 없이 HEAD 요청 한 번을 보냅니다. 링크와 폴더를 함께 점검하면 HTTPS 루트 GET 한 번과 코드에서 찾은 정적 경로 최대 5개의 HEAD 요청이 추가될 수 있습니다. 소스와 로그인 정보는 전송하지 않습니다. 코드 점검 시 127.0.0.1 테스트 서버 주소도 입력할 수 있으며 쿼리는 지원하지 않습니다.

설문 대조 결과

    내 프로젝트

    선택된 폴더 없음

    .env, 키 파일, 의존성·빌드 폴더는 제외합니다. 선택한 소스는 점검을 위해 이 Lockey 서버로 전송됩니다. Zoro-1에는 탐지 유형과 설문 선택값을 보내며, 직접 수정은 별도 동의 후 선택한 파일 전체를 모델 서버로 보냅니다. npm 잠금 파일이 있으면 패키지 이름과 버전을 OSV에 자동 대조합니다.
