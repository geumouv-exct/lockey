`src/credentials.mjs`의 하드코딩된 자격 증명을 제거했습니다. `configuredPassword()`는 기존 호출 방식과 반환 형식을 유지하며, 호출할 때마다 서버 환경 변수 `TRACE_DEMO_PASSWORD`에서 값을 읽습니다. 값이 없거나 빈 문자열이면 오류를 발생시킵니다.

- 수정 파일은 [src/credentials.mjs](/private/tmp/trace-ai-multi/secrets/src/credentials.mjs)와 [test/security.test.mjs](/private/tmp/trace-ai-multi/secrets/test/security.test.mjs)입니다.
- `npm test`는 수정 전 실패했고 수정 후 1개 테스트가 통과했습니다. 환경 변수 주입, 값 교체, 공백 보존, 누락 및 빈 값 처리를 검증했습니다.
- 작업공간 파일 3개를 검사해 원본 비밀값이 남아 있지 않음을 확인했습니다.

실제 자격 증명의 폐기·재발급, 운영 비밀 저장소 연동, 실제 악용 여부는 확인하지 못했습니다. 작업공간에 배포 설정이나 배포 산출물이 없었고, `npm pack`도 `package.json`에 `version`이 없어 실패했습니다. 따라서 배포 결과에 원본 값이 남아 있는지는 검증하지 못했습니다.
